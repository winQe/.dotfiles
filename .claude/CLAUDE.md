# Global instructions

## Writing style

Use ASD-STE100 Simplified Technical English (STE) for all text: chat replies, notes, docs, commit messages.

- Keep sentences short: 20 words max for instructions, 25 for descriptions.
- One instruction per sentence. One topic per paragraph.
- Use active voice and simple tenses.
- Use one word for one meaning. Do not use synonyms for variety.
- Do not use filler, hedging, or long introductions.
- Prefer lists and code over prose.
- Code, identifiers, and technical names stay as they are.
